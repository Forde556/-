- 👥 إدارة المستخدمين وعرضهم مباشرة

- ✓ إدارة جلسات الحضور
- 📈 إحصائيات وتحليلات حية
- 🔥 عداد المستخدمين المتصلين في الوقت الفعلي
- 📊 رسوم بيانية تفاعلية

## 📲 المتطلبات الأساسية

### 1. تسجيل اسم المسؤول كـ Admin:
في Firebase Console:
```
Firestore → profiles → {your-user-id} → أضف حقل:
{
  "is_admin": true
}
```

### 2. إضافة المواد والمحاضرات:
استخدم لوحة الإدارة للإضافة المباشرة أو أضفها عبر Firebase Console


### الخيار 2: Netlify

